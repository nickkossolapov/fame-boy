## Recommended resources

- [The Ultimate Game Boy Talk](https://www.youtube.com/watch?v=HyzD8pNlpwI) by Michael Steil at 33C3: a deep dive into the Game Boy's hardware and quirks.
- [Pan Docs](https://gbdev.io/pandocs/): the community-maintained Game Boy technical reference, invaluable when implementing an emulator.
- [Gekkio's Game Boy: Complete Technical Reference](https://gekkio.fi/files/gb-docs/gbctr.pdf): a detailed reference for the CPU and its instructions.
- [From NAND to Tetris](https://www.nand2tetris.org/): the course I used to learn the fundamentals of the CPU.
- [Guide to making a CHIP-8 emulator](https://tobiasvl.github.io/blog/write-a-chip-8-emulator/): a starting point for emulation, and the stepping stone before the Game Boy.
